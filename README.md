# Кейс-задача № 5

Программа на Python генерирует HTML-страницу с информацией об ООО «Веб-Центр».
В документ встроены CSS и JavaScript: страницу можно открыть без сервера.

## Запуск

Нужен Python 3.9 или новее. Дополнительные библиотеки не требуются.

```sh
python generate.py
```

После запуска открыть index.html двойным щелчком. Готовый index.html уже
включён в проект: его можно просмотреть и без установленного Python.

## Содержание

- Полное и сокращённое название, форма организации, ИНН и ОГРН.
- Основные услуги, адреса офисов и контакты.
- CSS для компьютеров и телефонов.
- Переключение шрифта всей страницы и шесть образцов для сравнения.

Основной вариант — Arial. Пять альтернатив: Verdana, Georgia,
Times New Roman, Trebuchet MS и Courier New.
Системные шрифты должны быть установлены на компьютере; иначе браузер
использует резервное семейство. В Windows перечисленные шрифты обычно доступны.

## Соответствие фирменному шрифту

Arial выбран для базового оформления. Он не обозначается как подтверждённый
официальный шрифт компании: CSS сайта при подготовке получить не удалось.
Для точного выполнения требования о совпадении шрифта нужно уточнить
font-family основного текста на web-c.ru через инструменты разработчика
браузера (Computed / Вычисленные стили) и повторить генерацию:

```sh
python generate.py --font "Название шрифта"
```

Если шрифт не установлен, можно встроить разрешённый к использованию файл:

```sh
python generate.py --font "Название шрифта" --font-file company.woff2
```

Файл будет закодирован в data URI: HTML останется автономным.
Поддерживаются WOFF2, WOFF, TTF и OTF. При выборе другого основного шрифта
генератор автоматически добавляет пять отличающихся от него альтернатив.

## Файлы

- generate.py — исходный код программы, данные организации, CSS и шаблон HTML.
- index.html — результат генерации, готовый к открытию в браузере.
- README.md — инструкция.

Все три файла находятся в одной папке; вложенные каталоги для запуска не нужны.
Для сдачи можно передать архив проекта либо загрузить эти файлы в новый
репозиторий GitHub и предоставить ссылку. Репозиторий кейса № 4 менять не нужно.
